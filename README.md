# Projeto POO - Classe Carro

## Sobre o projeto

O programa utiliza a linguagem Dart para aplicar conceitos de Programação Orientada a Objetos (POO), por meio da criação de uma classe `Carro`, com atributos e métodos para controlar sua velocidade.

## Funcionalidades

- Criar um objeto carro com modelo e velocidade máxima.
- Acelerar o carro, respeitando o limite de velocidade.
- Frear o carro, sem permitir velocidade negativa.
- Desligar o carro, zerando sua velocidade.
- Exibir o estado atual do carro no console.

## Tecnologias utilizadas

- Dart

## Conceitos aplicados

- Classes e objetos;
- Atributos;
- Construtor;
- Métodos;
- Estruturas condicionais (`if`).
